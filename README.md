# Kitty Snake: Yarn Trails

Offline-first grid Snake: a kitten collects fish, milk, yarn balls and golden fish while a pink yarn trail grows behind it.
One Godot 4.3 project exported to **Web (HTML5)**, **Windows** and **Android**. (iOS intentionally skipped — requires a paid Apple account.)

**Controls:** Arrows/WASD or gamepad D-pad; Esc/P/Start pauses; on touch devices an on-screen D-pad (or swipe, see Settings).
**Run:** open the folder in Godot 4.3 and press F5, or see `docs/build-and-export.md`. **Tests:** `docs/test-plan.md`.

Status: see `CHANGELOG.md` and the checklist in `docs/test-plan.md` for what is verified vs. still unbuilt.
